# California-House-price-prediction
To use it firstly train the moodel using code **python train.py --Windows** ,**python3 train.py --MacUser**


This project is  built with FastAPI that predicts California house prices using a Random Forest Regressor. It provides endpoints for both individual house price predictions and batch predictions through CSV file uploads. The API validates input data, processes multiple records efficiently,  returns predicted prices in a downloadable CSV format.
